# SC Vocoder 5

## v0.7.0

- 独立したディレイのパラメーター3項目・処理・状態・専用バッファを削除。互換用ダミー項目なし。
- 全17パラメーター。DSPメモリーを約256KiB削減。
- FLANGERの量に応じて最大約+3.01dBの自動ゲイン補正を追加。OUTPUT上限は+12dBを維持。
- 補正はフィードバックの外側に適用し、ループゲインを維持。
- リバーブ、コーラス、原音・MONITOR経路、最終リミッターを維持。

## v0.6.0

- 既存コーラスに加え、独立したフランジャー・ステレオディレイ・リバーブを追加。
- 追加エフェクトは初期値OFF。OFF時はv0.5.1と出力が完全一致。
- FLANGER / FLG RATE / REVERB / REV TIME / DELAY / DLY TIME / DLY FBを追加。
- 既存13パラメーターの番号・初期値、名称、ファイル名、unit IDを維持。
- MONITORは従来どおりエフェクトをバイパス。復帰時の古い残響を消去。
- 追加処理は固定バッファを使用。レンダリング中の動的確保・ロックなし。
- ホストDSP・SDK・追加エフェクトのテストとARMビルドを確認。実機確認は未実施。

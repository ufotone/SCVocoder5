# AGE Carrier v0.4.0

SCVocoder5用のキャリア・シンセ。AGE Carrier v0.1.1をベースに、単音トリガーから拡張和音・分数コードを生成するモードを追加しました。表示名は `AGE Carrier` です。

## 3つの動作モード

|MODE|動作|
|---|---|
|LIVE6（初期値）|従来のAGE Carrierと同じ最大6音のリアルタイム演奏。鍵盤で押さえた音をそのまま鳴らします。CHORD・ROOT・OCTAVEは使いません。|
|NOTE|シーケンサーやMIDIの単音をルートとして、CHORDで選んだ和音を生成します。ROOT・OCTAVEは使いません。|
|FIXED|本体のROOT・OCTAVE・CHORDから和音を生成します。シーケンサーのノート番号は発音／消音のトリガーとして使います。|

コード生成モードは1和音のみ発音します。新しいトリガーは前の和音を置き換え、6音リアルタイム演奏は無効です。最新のノートを離すと和音全体がリリースします。古いノートのNote Offでは新しい和音を止めません。モードを切り替えると発音中の音を消音します。

BASS=OFFなら従来どおりの基本形です。音名を指定すると、ルート以下で最も近いその音を最低音にします。指定音がコード内にあれば上の同じ音を低音へ移し、なければ追加します。NOTE / FIXEDはBASSを含めて最大4音です。5音になる場合は自然5度を省略し、自然5度がなければルートを省略します。変化した5度やテンションは残します。

9 / MAJ9 / MIN9 / 6/9 / M6/9はv0.3.0の5音構成から5度を省略した4音構成に変更しました。新しい11th / 13th系も、表のとおり一部の音を省略する4音ボイシングです。例: C9=C–E–Bb–D、C13=C–E–Bb–A。

LIVE6は従来の最大6音を維持します。コード生成時はオシレーターとエンベロープのレンダー処理を4音分に絞っています。実機でのCPU負荷の減少率は未測定です。

BASSはNOTE / FIXEDで有効で、LIVE6では無視します。NOTEではルートを入力ノートから取り、BASSは指定した絶対音名です（ルートからの相対音程ではありません）。CHORD・ROOT・OCTAVE・BASSの変更は次のトリガーから反映します。MIDI音域の上下限を超える場合はオクターブ単位で収めます。

## 例: Gm7 → Gm6 → Gm(♭6) → A♭M7/G

MODE=FIXED、OCTAVE=3、BASS=Gを共通設定にします。

|コード|ROOT|CHORD|BASS|実際に鳴る音|
|---|---|---|---|---|
|Gm7|G|MIN7|G|G3–Bb3–D4–F4|
|Gm6|G|MIN6|G|G3–Bb3–D4–E4|
|Gm(♭6)|G|MINb6|G|G3–Bb3–D4–Eb4|
|A♭M7/G|Ab|MAJ7|G|G3–Ab3–C4–Eb4|

各行の設定で単音をトリガーすると、表の和音全体を発音します。進行を鳴らすにはROOTとCHORDを各行に切り替えます。BASSはGのままです。コード名を文字列で打ち込む方式ではなく、ROOT・CHORD・BASSを選択する方式です。

## シーケンサーで使う

1. MULTIトラックでAGE Carrierを選びます。
2. MODEをNOTEまたはFIXEDにします。
3. CHORDを選びます。FIXEDではROOT・OCTAVEも設定します。分数コードにはBASSを設定します。
4. 単音のステップを入力します。1ステップで和音全体を発音します。
5. SC Vocoder 5のキャリアとして使います。ボコーダー側の接続・設定は既存のSCVocoder5と同じです。

NOTEではステップの音程からコード進行を作れます。FIXEDでは同じ設定の和音を各ステップで鳴らします。

## ビルドとインストール

同梱の `age_carrier.drmlgunit` をdrumlogueの `Units/Synths/` へコピーしてください。

Dockerとlogue-sdkが使える環境で:

```powershell
./build.ps1 -SdkRoot 'C:\path\to\logue-sdk'
```

SDKの `platform/drumlogue/age-carrier-v040` が未使用であることを確認してください。ビルド成功後の `age_carrier.drmlgunit` をdrumlogueの `Units/Synths/` へコピーします。元のAGE Carrierと同じunit ID（ACR1）を使う改良版です。従来のAGE Carrierを更新します。

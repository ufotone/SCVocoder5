# AGE Carrier

## v0.4.0

- NOTE / FIXEDの生成音をBASS込みで最大4音に統一。
- 9 / MAJ9 / MIN9 / 6/9 / M6/9は5度を省略。既存の選択番号は維持。
- コード外のBASSで5音になる場合は自然5度、なければルートを省略。
- 7b5 / 7#5 / M7#5 / 7b9 / 7#9 / 7#11 / 7b13 / 13 / M13 / m13 / 11 / m11 / 7SUS2 / M7S2 / M7S4 / ADD11 / MAD11の17種類を追加し、全40種類に拡張。
- コード生成時のレンダーを4音分に制限。LIVE6は従来の6音演奏を維持。
- 実機のCPU負荷軽減率は未測定。

## v0.3.0

- コードを10種類から23種類に拡張。MIN6・MINb6・各種9th・add9・6/9などを追加。
- BASSで転回形・分数コードに対応。構成音の重複を避け、最大6音で発音。
- Gm7 → Gm6 → Gm(♭6) → AbM7/Gの構成音と波形を検証。
- 黒鍵の音名をDb / Eb / Gb / Ab / Bb表記に変更。音程・保存値は維持。
- 既存8パラメーター・10コードの番号と初期モードLIVE6を維持。BASSの初期値はOFF。

## v0.2.0

- 初期値は従来の6音リアルタイム演奏（LIVE6）。
- 単音をルートとするコード生成（NOTE）、本体でルート・コード・オクターブを指定するコード生成（FIXED）を追加。
- 3和音6種類・4和音4種類。コード生成中は6音リアルタイム演奏を無効化。
- MODEの表示をLIVE6 / NOTE / FIXEDへ短縮。
- 名称はAGE Carrier、ビルドプロジェクト名とファイル名はage_carrier。
- 元のunit ID ACR1を維持。従来のADR / LEVELの番号0〜3を維持し、コード設定を番号4〜7に追加。
- 初期試作ACHとは識別子・パラメーター配置が異なります。AGE Carrier v0.1.1からの改良版として配布します。
